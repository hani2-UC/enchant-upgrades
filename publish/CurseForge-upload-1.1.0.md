# CurseForgeへの1.1.0アップロード

各JARを個別のファイルとして添付し、対応するMinecraftバージョンとローダーを選んでください。複数のJARをmodsフォルダーへ同時に入れる必要はありません。

| ファイル | Minecraft | ローダー |
|---|---|---|
| enchant_upgrades-forge-1.20.1-1.1.0.jar | 1.20.1 | Forge |
| enchant_upgrades-fabric-1.20.1-1.1.0.jar | 1.20.1 | Fabric |
| enchant_upgrades-fabric-1.21.1-1.1.0.jar | 1.21.1 | Fabric |
| enchant_upgrades-fabric-1.21.4-1.1.0.jar | 1.21.4 | Fabric |
| enchant_upgrades-neoforge-1.21.1-1.1.0.jar | 1.21.1 | NeoForge |
| enchant_upgrades-neoforge-1.21.4-1.1.0.jar | 1.21.4 | NeoForge |

ファイル種別はRelease。Fabric版にはFabric APIを必須依存関係として指定してください。

更新内容は `CHANGELOG-1.1.0.md`、プロジェクト説明の更新案は `curseforge-description-1.1.0.md` にあります。
最初に添付していた1.0.0はForge 1.20.1専用です。1.1.0のForge版も同じ仕組み・コストなので、1.0.0で始めたワールドを継続できます。
